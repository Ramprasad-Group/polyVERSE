# ROMP-Recipes

This folder contains the requested review materials for the manuscript:

**Mechanism-Informed Artificial Intelligence Framework for Predicting Polymer Synthesis Procedures: Application to Ring-Opening Metathesis Polymerization**

The materials were prepared for Nature Communications manuscript NCOMMS-26-063049.

## Contents

- `checklists/`: completed Machine Learning Checklist and Code and Software Submission Checklist requested by Nature Communications.
- `Code_package/`: representative source code, dependencies, README, demo commands, example data, and expected outputs.

## Notes

The code package is intended for editorial and peer-review evaluation. The representative example dataset is provided to demonstrate code execution and data format, not to reproduce the full manuscript performance metrics.

The full curated datasets and full manuscript-level reproduction materials will be made available according to the Code Availability and Data Availability statements upon publication.
